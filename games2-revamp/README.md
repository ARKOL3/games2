# Vertex

A fast, lightweight, clean game site.

Built on [3kh0-lite](https://github.com/3kh0/3kh0-lite) by 3kh0, used with credit.

## Structure
- `css/style.css`: all styling. Colors and fonts live in the `:root` variables at the top.
- `js/main.js`: ads (off until you add your own `AD_CLIENT`) and saved tab cloak.
- `config/games.json`: game names, icons, and links.

## Run it
Host the folder on any static web host (Vercel, GitHub Pages, etc.).

## Renaming later
Search the project for `Vertex` and replace it (titles, brand link, footer, subtitle.js).
